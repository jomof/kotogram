# recon_bpd_test.txt — Broad-spectrum grammar reconstruction probes
# ═══════════════════════════════════════════════════════════════════
# Format: <full_sentence>: <masked_variant_1> [<masked_variant_2> ...]
# Each 'x' replaces one surface token. Adjacent 'xx' = two consecutive.
#
# Organized by grammatical phenomenon to diagnose which KC dimensions
# are capturing which linguistic features.
# ═══════════════════════════════════════════════════════════════════

# ── §1 Case Particles (が, を, に, で, から, まで, と, へ, も) ─────
# The minimal grammatical signal. If the model can't reconstruct
# these, it hasn't learned basic Japanese syntax.
雨が降る: 雨x降る
本を読む: 本x読む
学校に行く[学校へ行く]: 学校x行く
花が咲く: 花x咲く
春に桜が咲く: 春x桜が咲く 春に桜x咲く
公園で遊ぶ: 公園x遊ぶ
東京から来た: 東京x来た
海へ行く[海に行く]: 海x行く
友達と話す: 友達x話す

# ── §2 Topic vs Subject (は vs が) ────────────────────────────────
# Critical distinction. は marks known/topical information,
# が marks new/focused information. Tests pragmatic awareness.
猫は魚が好きだ: 猫x魚が好きだ 猫はxx好きだ
私は学生です: 私x学生です
誰が来ましたか[誰か来ましたか]: 誰x来ましたか

# ── §3 Sentence-Final Particles (ね, よ, か, な, わ) ─────────────
# Pragmatic/mood markers at sentence boundary. Position-sensitive.
寒いですね: 寒いですx
元気ですか[元気ですね]: 元気ですx
面白いよ: 面白いx
行きたいな[行きたいです]: 行きたいx
夜の風が冷たいね[夜は風が冷たいね]: 夜x風が冷たいね

# ── §4 Copula & Sentence Endings (だ, です, である) ──────────────
# Formality register encoded in the final element.
これは本だ[これは本です]: これは本x
これは本です[これは本だ]: これは本x
これは本である: これは本xある
これは本ではない: これは本xはない これは本でxない

# ── §5 Verb Conjugation (て, た, ない, ます, passive, causative) ──
# Tests whether KCs capture morphological paradigm structure.
# 食べる is one token (terminal form), so no mask possible.
ご飯を食べた: ご飯をxた
野菜を食べない: 野菜をxない
朝食を食べます: 朝食をxます
何でも食べられる: 何でもxられる
野菜を食べさせる: 野菜をxさせる
ご飯を食べている: ご飯をxxいる
お寿司を食べたい: お寿司をxたい

# ── §6 い-Adjective Inflection ───────────────────────────────────
# Adjective stem should be reconstructable from conjugated form.
夏は暑い日が続く: 夏はx日が続く
夏なのに暑くない: 夏なのにxない
夏の日が暑かった: 夏の日がxた

# ── §7 な-Adjective + Copula ─────────────────────────────────────
静かな夜だ: 静かx夜だ
静かだった: 静かxた
静かではない: 静かxxない

# ── §8 Content Word Prediction (Semantic KC Test) ────────────────
# Can the model infer a content word purely from syntactic frame?
# These test semantic KC capacity, not just grammar.
喉が渇いて水を飲む[喉が渇いて酒を飲む]: 喉が渇いてxを飲む
友達を駅で待つ: 友達をxで待つ
封筒に入れる手紙を書く: 封筒に入れるxを書く
ヘッドフォンで音楽を聴く: ヘッドフォンでxを聴く
映画館で映画を見る: 映画館でxを見る

# ── §9 Compound Particles (について, のために) ───────────────────
# Multi-token grammatical constructions.
# について = に + つい + て (3 tokens); のために = の + ため + に
日本について話す: 日本xxx話す
将来のために勉強する: 将来xxx勉強する

# ── §10 Conditional Forms (ば, たら, なら, と) ────────────────────
# Different conditional semantics encoded in suffixes.
雨が降れば中止だ: 雨が降れx中止だ
雨が降ったら中止だ: 雨がxx中止だ
時間があれば行く: 時間がxば行く

# ── §11 て-Form Chaining ─────────────────────────────────────────
# Sequential actions linked by て. Tests multi-clause structure.
起きて顔を洗う: 起きx顔を洗う
歩いて学校に行く[歩いて学校へ行く]: 歩いx学校に行く 歩いて学校x行く

# ── §12 Relative Clauses ─────────────────────────────────────────
# Prenominal modification. Token order signals embedding.
昨日買った本: 昨日xx本
母が作った料理: 母x作ったx 母が作ったx

# ── §13 Keigo / Politeness Register ──────────────────────────────
# Honorific (尊敬語), humble (謙譲語), polite (丁寧語).
先生がいらっしゃる: 先生xいらっしゃる
先生に申し上げる: 先生x申し上げる
お水をください: お水xください

# ── §14 Giving/Receiving (あげる/もらう/くれる) ───────────────────
# Directional benefactive verbs — uniquely Japanese.
友達に本をあげる: 友達に本xあげる
友達が本をくれた: 友達が本xくれた
友達に本をもらった: 友達に本xもらった

# ── §15 Quotation と ─────────────────────────────────────────────
嘘だと思った[嘘だって思った]: 嘘だx思った
行くと言った: 行くx言った

# ── §16 Longer Sentences (8+ tokens) ─────────────────────────────
# Stress-tests bottleneck capacity for complex multi-clause input.
東京から大阪まで行く: 東京x大阪まで行く 東京から大阪x行く
東京から大阪まで新幹線で行く: 東京x大阪まで新幹線で行く 東京から大阪x新幹線で行く 東京から大阪まで新幹線x行く
毎朝早く起きて公園を走る: 毎朝早く起きて公園x走る
日本語を勉強している学生が多い: 日本語x勉強している学生が多い

# ── §17 Negation Scope ───────────────────────────────────────────
全然分からない: 全然xない
まだ届いていない: まだ届いxいない
何も食べなかった[何か食べなかった]: 何x食べなかった

# ── §18 Temporal/Aspectual (ている, てある, てしまう, ておく) ────
窓が開いている: 窓が開いxいる
窓が開けてある: 窓が開けxある
食べてしまった: 食べxしまった
準備しておく: 準備xxおく

# ── §19 Sentence-Medial Conjunctions (けど, から, ので) ──────────
高いけど買った[高いから買った]: 高いx買った
疲れたから休む: 疲れたx休む
寒いので窓を閉めた: 寒いxx窓を閉めた

# ── §20 Counter/Classifier Expressions ───────────────────────────
左右と真ん中に猫が三匹いる: 左右と真ん中に猫がx匹いる 左右と真ん中に猫が三xいる
上下巻の本を二冊買った: 上下巻の本をx冊買った
