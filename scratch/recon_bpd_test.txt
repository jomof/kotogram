# ═══════════════════════════════════════════════════════════════════
# recon_bpd_test.txt — Broad-spectrum grammar reconstruction probes
# ═══════════════════════════════════════════════════════════════════
# Format: <full_sentence>: <masked_variant_1> [<masked_variant_2> ...]
# Each 'x' replaces one surface token. Adjacent 'xx' = two consecutive.
#
# Organized by grammatical phenomenon to diagnose which KC dimensions
# are capturing which linguistic features.
# ═══════════════════════════════════════════════════════════════════

# ── Case Particles (が, を, に, で, から, まで, と, へ, も) ─────
# The minimal grammatical signal. If the model can't reconstruct
# these, it hasn't learned basic Japanese syntax.
雨が降る: 雨x降る
本を読む: 本x読む
学校に行く[学校へ行く]: 学校x行く
花が咲く: 花x咲く
春に桜が咲く[春の桜が咲く]: 春x桜が咲く 春に桜x咲く
公園で遊ぶ: 公園x遊ぶ
東京から来た[東京に来た]: 東京x来た
海へ行く[海に行く]: 海x行く
友達と話す: 友達x話す

# ── Topic vs Subject (は vs が) ────────────────────────────────
# Critical distinction. は marks known/topical information,
# が marks new/focused information. Tests pragmatic awareness.
猫は魚が好きだ: 猫x魚が好きだ 猫はxx好きだ
私は学生です: 私x学生です
誰が来ましたか[誰か来ましたか]: 誰x来ましたか

# ── Sentence-Final Particles (ね, よ, か, な, わ) ─────────────
# Pragmatic/mood markers at sentence boundary. Position-sensitive.
寒いですね[寒いですよ]: 寒いですx
元気ですか[元気ですね]: 元気ですx
面白いよ[面白いです]: 面白いx
行きたいな[行きたいです,行きたいよ]: 行きたいx
夜の風が冷たいね[夜は風が冷たいね]: 夜x風が冷たいね

# ── Copula & Sentence Endings (だ, です, である) ──────────────
# Formality register encoded in the final element.
これは本だ[これは本です]: これは本x
これは本です[これは本だ]: これは本x
これは本である: これは本xある
これは本ではない: これは本xはない これは本でxない

# ── Verb Conjugation (て, た, ない, ます; passive adds られ, causative adds させ) ──
# Tests whether KCs capture morphological paradigm structure.
# 食べる is one token (terminal form), so no mask possible.
ご飯を食べた: ご飯をxた
野菜を食べない: 野菜をxない
朝食を食べます: 朝食をxます
何でも食べられる[何でも見られる]: 何でもxられる
野菜を食べさせる: 野菜をxさせる
ご飯を食べている[ご飯を作っている]: ご飯をxxいる
お寿司を食べたい: お寿司をxたい

# ── い-Adjective Inflection (い changes to かった in past) ────────────────
# Adjective stem should be reconstructable from conjugated form.
夏は暑い日が続く: 夏はx日が続く
夏なのに暑くない: 夏なのにxない
夏の日が暑かった: 夏の日がxた

# ── な-Adjective + Copula (な dropped for だった, ではない) ─────────────────
静かな夜だ: 静かx夜だ
静かだった[静かでした]: 静かxた
静かではない: 静かxxない

# ── Content Word Prediction (Semantic KC Test) ────────────────
# Can the model infer a content word purely from syntactic frame?
# These test semantic KC capacity, not just grammar.
友達を駅で待つ: 友達をxで待つ
ヘッドフォンで音楽を聴く: ヘッドフォンでxを聴く
映画館で映画を見る: 映画館でxを見る

# ── Compound Particles (について, のために) ───────────────────
# Multi-token grammatical constructions.
# について = に + つい + て (3 tokens); のために = の + ため + に
日本について話す: 日本xxx話す
将来のために勉強する: 将来xxx勉強する

# ── Conditional Forms (ば, たら, なら, と) ────────────────────
# Different conditional semantics encoded in suffixes.
雨が降れば中止だ: 雨が降れx中止だ
雨が降ったら中止だ: 雨がxx中止だ
時間があれば行く: 時間がxば行く

# ── て-Form Chaining ─────────────────────────────────────────
# Sequential actions linked by て. Tests multi-clause structure.
起きて顔を洗う: 起きx顔を洗う
歩いて学校に行く[歩いて学校へ行く]: 歩いx学校に行く 歩いて学校x行く

# ── Relative Clauses ─────────────────────────────────────────
# Prenominal modification. Token order signals embedding.
昨日買った本: 昨日xx本
母が作った料理: 母x作ったx 母が作ったx

# ── Keigo / Politeness Register ──────────────────────────────
# Honorific (尊敬語), humble (謙譲語), polite (丁寧語).
先生がいらっしゃる: 先生xいらっしゃる
先生に申し上げる: 先生x申し上げる
お水をください: お水xください

# ── Giving/Receiving (あげる/もらう/くれる) ───────────────────
# Directional benefactive verbs — uniquely Japanese.
友達に本をあげる: 友達に本xあげる
友達が本をくれた: 友達が本xくれた
友達に本をもらった: 友達に本xもらった

# ── Quotation と ─────────────────────────────────────────────
嘘だと思った[嘘だって思った]: 嘘だx思った
行くと言った: 行くx言った

# ── Longer Sentences (8+ tokens) ─────────────────────────────
# Stress-tests bottleneck capacity for complex multi-clause input.
東京から大阪まで行く[東京から大阪へ行く]: 東京x大阪まで行く 東京から大阪x行く
東京から大阪まで新幹線で行く: 東京x大阪まで新幹線で行く 東京から大阪x新幹線で行く 東京から大阪まで新幹線x行く
毎朝早く起きて公園を走る: 毎朝早く起きて公園x走る
日本語を勉強している学生が多い[日本語は勉強している学生が多い]: 日本語x勉強している学生が多い

# ── Negation Scope ───────────────────────────────────────────
全然分からない[全然わからない]: 全然xない
まだ届いていない: まだ届いxいない
何も食べなかった[何か食べなかった]: 何x食べなかった

# ── Temporal/Aspectual (ている, てある, てしまう, ておく) ────
窓が開いている: 窓が開いxいる
窓が開けてある: 窓が開けxある
食べてしまった: 食べxしまった
準備しておく: 準備xxおく

# ── Sentence-Medial Conjunctions (けど, から, ので) ──────────
高いけど買った[高いから買った]: 高いx買った
疲れたから休む[疲れたゆっくり休む]: 疲れたx休む
寒いので窓を閉めた: 寒いxx窓を閉めた

# ── Counter/Classifier Expressions ───────────────────────────
左右と真ん中に猫が三匹いる[左右と真ん中に猫が3匹いる]: 左右と真ん中に猫がx匹いる 左右と真ん中に猫が三xいる
上下巻の本を二冊買った[上下巻の本を一冊買った]: 上下巻の本をx冊買った

# ═══════════════════════════════════════════════════════════════════
# Grammar Patterns (established JLPT patterns)
# ═══════════════════════════════════════════════════════════════════
# Tests whether the model discovers multi-token grammar patterns,
# especially NON-ADJACENT correlated features. These are established
# Japanese grammar points where masking one element should be
# recoverable from the surrounding grammatical frame.
# ═══════════════════════════════════════════════════════════════════

# ── というのは...事実だ (it is a fact that) ──────────────────────
# Quotative frame: という signals factual/evidential conclusion.
# Masking 事実 tests whether the model links という to a factual
# predicate across intervening tokens.
彼が辞めたというのは事実だ[彼が辞めたというのは本当だ]: 彼が辞めたというのはxだ
地球が丸いというのは事実だ[地球が丸いというのは本当だ]: 地球が丸いというのはxだ

# ── 価値がない (to be worthless) ─────────────────────────────────
# Fixed collocation: Verb+価値がない is a set pattern.
読む価値がない[読む必要がない,読む意味がない]: 読むxがない
行く価値がない[行く必要がない,行く意味がない]: 行くxがない

# ── あまり...ない (not very/much) ────────────────────────────────
# NON-ADJACENT pattern: あまり signals upcoming negation.
# Single mask: can the model predict あまり from downstream ない?
この映画はあまり面白くない[この映画は全然面白くない]: この映画はx面白くない
最近あまり寝ていない[最近全然寝ていない]: 最近x寝ていない
# Reverse: given あまり, can it predict ない at the boundary?
あまり美味しくない: あまり美味しくx
# NON-ADJACENT double mask: can the model reconstruct BOTH ends
# of the pattern simultaneously?
この映画はあまり面白くない: この映画はx面白くx

# ── ほかに (other besides) ───────────────────────────────────────
# ほか pairs with に to form "besides/other than."
ほかに方法がない: xに方法がない
ほかには何もない: xには何もない


# ── 少しずつ (little by little) ──────────────────────────────────
# Fixed adverbial pattern: 少し + ずつ.
少しずつ上手になる: xずつ上手になる

# ── とっくに (long ago / already) ────────────────────────────────
# とっくに splits as とっく+に (2 tokens); double mask.
宿題はとっくに終わった: 宿題はxx終わった
電車はとっくに出た: 電車はxx出た

# ── は〜くらいです (about the only) ─────────────────────────────
# NON-ADJACENT pattern: は...くらい frame signals limitation.
# The は earlier in the sentence sets up the くらい conclusion.
分かるのは名前くらいです[分かるのは名前だけです]: 分かるのは名前xです
できるのは料理くらいです[できるのは料理だけです]: できるのは料理xです

# ── と同じくらい (about the same as) ────────────────────────────
# Fixed frame: と_くらい with 同じ as the expected link.
兄と同じくらい背が高い: 兄とxくらい背が高い
東京と同じくらい暑い: 東京とxくらい暑い

# ── のこと (about / concerning) ──────────────────────────────────
# Abstract nominalizer のこと in idiomatic patterns.
# These contexts strongly prefer こと over concrete nouns.
将来のことを考える: 将来のxを考える
日本のことを勉強する: 日本のxを勉強する
彼女のことをよく知っている: 彼女のxをよく知っている

# ── について・に関して (about/regarding) ─────────────────────────
# Synonym compound particles. について: に+つい+て (3 tokens).
# に関して: に+関し+て (3 tokens).
環境問題について議論する[環境問題に関して議論する]: 環境問題xxx議論する
この件に関して報告する[この件について報告する]: この件xxx報告する

# ── ともなく (absentmindedly / without intending) ────────────────
# Fixed pattern: Verb + ともなく + same or related verb. ともなく = と+も+なく (3 tokens).
見るともなくテレビを見ていた: 見るxxxテレビを見ていた
聞くともなく話を聞いていた: 聞くxxx話を聞いていた

# ── どうにもこうにも〜ない (absolutely no way) ──────────────────
# どう+に+も+こう+に+も (6 tokens).
どうにもこうにも眠れない: xxxxxx眠れない
どうにもこうにも動けない: xxxxxx動けない

# ── 絶対に〜ない (absolutely not) ───────────────────────────────
# NON-ADJACENT: 絶対に at start demands negation at end.
# 絶対 is 1 token, に is 1 token.
# Single masks — predict 絶対 from the negative frame:
約束は絶対に忘れない[約束は本当に忘れない]: 約束はxに忘れない
彼は絶対に諦めない[彼は本当に諦めない]: 彼はxに諦めない
# Reverse — predict ない given 絶対に:
絶対に負けない: 絶対に負けx
# NON-ADJACENT double mask — both ends simultaneously:
約束は絶対に忘れない: 約束はxに忘れx

# ── 豊富 (abundant/rich) ────────────────────────────────────────
# な-adjective in attributive contexts that constrain toward 豊富.
資源が豊富な国だ[資源が重要な国だ]: 資源がxな国だ
経験が豊富な先生だ: 経験がxな先生だ

# ── によると・によれば (according to) ───────────────────────────
# Evidential/hearsay frame. Synonym pair.
# によると: に+よる+と (3 tokens); によれば: に+よれ+ば (3 tokens).
天気予報によると明日は雨だ[天気予報によれば明日は雨だ]: 天気予報xxx明日は雨だ
ニュースによれば事故があった[ニュースによると事故があった]: ニュースxxx事故があった

# ── 向かい (across from) ────────────────────────────────────────
# Spatial noun. Context constrains to location-relative words.
駅の向かいに店がある[駅の前に店がある,駅の隣に店がある,駅の近くに店がある]: 駅のxに店がある
学校の向かいに公園がある[学校の前に公園がある,学校の隣に公園がある]: 学校のxに公園がある

# ── も...も (parallel addition particle) ────────────────────────
# Parallel structure: first も is recoverable from second も.
猫も犬も好きだ: 猫x犬も好きだ
子供も大人も楽しめる: 子供x大人も楽しめる
# Reverse — predict second も from first:
猫も犬も好きだ: 猫も犬x好きだ
# NON-ADJACENT double mask — both particles:
猫も犬も好きだ: 猫x犬x好きだ

# ── 又〜も (additionally) ───────────────────────────────────────
# 又 is a single token (not normalized to また).
又失敗もしてしまった: x失敗もしてしまった
彼は又遅刻もした: 彼はx遅刻もした

# ── 的 (adjectivizer suffix) ───────────────────────────────────
# noun+的 forms a single token; masks the whole compound.
科学的な研究だ: xな研究だ
積極的に参加する: xに参加する
歴史的な建物だ: xな建物だ

# ── 誰も〜ない (no one / nobody) ───────────────────────────────
# NON-ADJACENT: 誰も demands negation at end.
# 誰+も are separate tokens; mask 誰, leave も visible.
誰も来なかった: xも来なかった
教室に誰もいなかった: 教室にxもいなかった
